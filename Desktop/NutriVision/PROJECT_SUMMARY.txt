### Windows
```
1. Double-click: start.bat
2. Type: 1 (then Enter)
3. Wait 30 seconds
4. Browser opens at http://localhost:3000
Done! ✅
```

### Mac/Linux
```bash

./start.sh
# Choose option 1
# Browser opens at http://localhost:3000
```

### Manual
```bash
# Terminal 1: Backend
cd NutriVision
mvn spring-boot:run

# Terminal 2: Frontend
cd NutriVision/frontend
npm install
npm start
```

**Visit:** http://localhost:3000

## 🚨 COMMON ISSUES & SOLUTIONS

| Issue | Solution |
|-------|----------|
| Backend won't start | Check MySQL running, verify credentials |
| Frontend can't connect | Ensure backend on port 8080, check CORS |
| Port 3000 in use | Try `PORT=3001 npm start` |
| npm install fails | Delete node_modules, clear cache, retry |
| Database error | Check credentials, create database |

*See HELP.md for detailed solutions*
