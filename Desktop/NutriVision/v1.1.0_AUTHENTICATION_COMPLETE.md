## 🔐 How Security Works

### Token Management
```
1. User logs in
   → Backend generates JWT token
   → Frontend receives token
   → Stored in localStorage

2. User makes API call
   → axios interceptor reads token
   → Automatically adds to request header
   → "Authorization: Bearer [token]"

3. Backend validates token
   → SecurityConfig checks JWT
   → If valid: Process request
   → If invalid: Return 401

4. If 401 response
   → axios interceptor catches
   → Clears localStorage
   → Redirects to /login
   → Session ended
```

### Protected Routes
- Cannot access Dashboard without login
- Cannot access Foods without login
- Cannot access Recipes without login
- Redirects to login if token expires
- User data stored in React Context
